# agent

[项目地址 minion Agent框架](https://github.com/yikaikkk/minion)

## Agent 短期记忆
### 存储方式
- 内存存储 ：使用 conversation_history 列表存储对话历史
- 数据结构 ：每个条目包含角色、内容和时间戳
- 非持久化 ：程序重启后记忆会丢失
### 核心功能
- 对话历史记录 ：通过 add_to_history 方法添加对话条目
- 上下文管理 ：通过 _add_conversation_context 方法将历史对话作为上下文添加到新输入中
- 状态追踪 ：使用 persistent_state 字典存储会话计数、变量、记忆和学习模式
- 状态重置 ：通过 reset_state 方法重置状态，保留学习到的模式
### 使用场景
- 当前会话 ：保持对话的连贯性和一致性
- 上下文理解 ：在处理新任务时考虑之前的对话内容
- 短期模式学习 ：从当前会话中学习模式和偏好
## Brain 长期记忆
### 存储方式
- 持久化存储 ：使用 mem0 库实现长期记忆
- 可配置 ：通过 memory_config 参数配置存储方式
- 延迟加载 ：通过 _get_memory_class 函数延迟加载 mem0，减少启动时间
### 核心功能
- 记忆存储 ：将重要信息存储到持久化存储中
- 记忆检索 ：根据查询检索相关记忆
- 记忆管理 ：管理记忆的生命周期和优先级
### 使用场景
- 长期知识积累 ：存储和积累长期知识
- 跨会话记忆 ：在不同会话之间保留重要信息
- 知识检索 ：在处理新任务时检索相关的长期记忆
## 记忆系统的协同工作
1. 短期与长期记忆结合 ：
   
   - Agent 使用短期记忆保持当前会话的上下文
   - Brain 使用长期记忆存储和检索长期知识
   - 两者结合，使得系统既能够保持当前会话的连贯性，又能够积累和利用长期知识
2. 记忆管理流程 ：
   
   - 新输入 → Agent 短期记忆处理 → Brain 长期记忆检索 → 执行任务 → 结果存储到短期记忆 → 重要信息存储到长期记忆
3. 优势 ：
   
   - 上下文连续性 ：保持对话的连贯性和一致性
   - 知识积累 ：从交互中学习模式，提高未来任务的处理能力
   - 状态持久化 ：支持跨会话的记忆持久化
   - 资源优化 ：通过记忆管理，避免重复计算和处理
